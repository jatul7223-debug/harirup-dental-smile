# Harirup Smile Design

Build a modern, clean, professional website for a dental clinic called 

"Harirup Dental Care" run by Dr. Harish Khamkar, located near Manchar, 

Patilwada, Manchar, Maharashtra 410503.

DESIGN STYLE:

- Clean, minimal, medical/healthcare aesthetic

- Color palette: soft white/light blue/teal tones (calming, trustworthy, 

  dental-clinic feel) with one accent color

- Generous white space, rounded cards, soft shadows

- Modern sans-serif typography (good heading hierarchy)

- Fully responsive (mobile-first), fast loading

- Smooth scroll animations and subtle hover effects (no clutter)

DO NOT use any stock/placeholder photos. Only use the images I upload 

to the project. If no image is uploaded yet for a section, leave a 

clearly marked placeholder box instead of inserting a random photo.

PAGES / SECTIONS (single-page site with smooth-scroll nav):

1. Header/Navbar

   - Clinic logo/name, sticky on scroll

   - Nav links: Home, About, Services, Gallery, Reviews, Contact

   - "Book Appointment" button (prominent, accent color)

   - Mobile hamburger menu

2. Hero Section

   - Clinic name, tagline (e.g. "Caring for Your Smile, Naturally")

   - Short intro line about Dr. Harish Khamkar

   - Primary CTA: "Book an Appointment"

   - Secondary CTA: "Call Now" (click-to-call button with clinic phone number)

   - Uploaded hero image of the clinic

3. About Section

   - About Dr. Harish Khamkar (qualifications, experience — placeholder 

     text I can edit later)

   - About the clinic, mission/values

   - Trust badges: years of experience, patients treated, certifications

4. Services Section

   - Grid/card layout for services: General Dentistry, Root Canal 

     Treatment, Teeth Cleaning & Whitening, Braces/Orthodontics, 

     Dental Implants, Cosmetic Dentistry, Tooth Extraction, 

     Pediatric Dentistry, Emergency Dental Care

   - Icon + short description for each

   - Each card has a "Learn More" expandable or modal

5. Why Choose Us

   - Modern equipment, hygienic environment, experienced doctor, 

     painless treatment, affordable pricing, flexible timing

6. Gallery Section

   - Grid for clinic photos (use only uploaded images, labeled 

     placeholders if missing)

   - Lightbox view on click

7. Patient Reviews/Testimonials

   - Carousel/slider with star ratings

   - Option to "Read more reviews on Google" linking to: 

     https://maps.app.goo.gl/xDSEkd3igUhU8N7q6

8. Location & Contact Section

   - Embed the actual Google Map for this location using this iframe:

     <iframe 

       src="https://www.google.com/maps?q=Harirup+Dental+Care+Dr+Harish+Khamkar+Patilwada+Manchar+Maharashtra+410503&output=embed" 

       width="100%" height="450" style="border:0;" 

       allowfullscreen loading="lazy">

     </iframe>

   - Clinic address, phone number, email, opening hours (Mon–Sat)

   - "Get Directions" button linking to: 

     https://maps.app.goo.gl/xDSEkd3igUhU8N7q6

   - Contact form (Name, Phone, Email, Preferred date/time, Message) 

     that sends to a placeholder email

9. Appointment Booking

   - Simple booking form/modal: Name, Phone, Service needed, 

     Preferred Date & Time

   - Confirmation message after submit

10. Floating Action Buttons (latest must-have features)

   - WhatsApp chat button (bottom-right floating icon)

   - Click-to-call button

   - "Back to top" button

11. Footer

   - Clinic name, address, quick links, social media icons, 

     Google Maps link, copyright

ADDITIONAL FEATURES TO INCLUDE:

- Dark/light mode toggle

- SEO basics: meta title, meta description, alt text for all images

- Fast page load, lazy-loaded images

- Accessibility: proper contrast, alt tags, keyboard navigation

- FAQ accordion section (common dental questions)

- Loading skeleton/animation on page load

- 404 page matching site theme

TECH NOTES:

- Use placeholder text in [brackets] anywhere real content (phone 

  number, email, exact hours, doctor bio, pricing) is missing, so I 

  can edit it easily later.

- Keep the code clean and component-based for easy future edits.
